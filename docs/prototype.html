YouTube-first prototype

Analyze a channel, then find creator partners.

CollabMatch asks for a YouTube channel, builds a public-profile based creator brief, and recommends collaborators by niche, audience fit, geography, engagement, and content style. It works with mock profiling by default and can use the YouTube Data API when you add a key.
