# Tandem mobile/web app (Flutter)

This package contains only the cross-platform Dart code. The native iOS/Android
shells and platform-specific resource folders are generated by the Flutter SDK.

## One-time bootstrap

```powershell
cd apps/mobile
flutter create . --platforms=ios,android,web --org app.tandem --project-name tandem
dart pub global activate flutterfire_cli
flutterfire configure --project tandem-dev --out lib/core/firebase/firebase_options.dart
flutter pub get
dart run build_runner build --delete-conflicting-outputs
```

`flutter create .` merges the missing native folders into this existing directory
without overwriting any of the Dart files already checked in.

## Run

```powershell
# With Firebase emulators:
flutter run -d chrome --dart-define=USE_EMULATOR=true

# Production / staging Firebase:
flutter run -d chrome --dart-define=RECAPTCHA_SITE_KEY=<your key>
```

## Build web (for Firebase Hosting `app` target)

```powershell
flutter build web --release --dart-define=RECAPTCHA_SITE_KEY=<your key>
```
